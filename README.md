### kern0x1b

Reverse-engineering software that stopped working when someone else's API
changed — old iOS jailbreak tweaks, dev tooling built to outlive the next
version bump.

- **[cef-openapi-generator](https://github.com/kern0x1b/cef-openapi-generator)** — OpenAPI code generator for JetBrains/CEF plugins. 99%+ instruction coverage, real integration tests, not a demo.
- **[vscode-intellij-code-formatter](https://github.com/kern0x1b/vscode-intellij-code-formatter)** — runs IntelliJ IDEA's actual formatting engine headlessly. No reimplementation, no drift from the real thing.
- **[vscode-intellij-theme](https://github.com/kern0x1b/vscode-intellij-theme)** — IntelliJ IDEA Islands colors, ported to VS Code.
- **[cydia](https://github.com/kern0x1b/cydia)** — a small Cydia source keeping a couple of iOS 6 apps working after their backends moved on without them.
- **[kindle-sync-fix](https://github.com/kern0x1b/kindle-sync-fix)** — MobileSubstrate tweak fixing a dead Kindle Whispersync sync on jailbroken iOS 6.
- **[clipstash](https://github.com/kern0x1b/clipstash)** — a menu-bar clipboard manager, maintained fork.

No stats widget, no streak graph — the commits speak for themselves.
