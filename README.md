### kern0x1b

Reverse-engineering software that stopped working when someone else's API
changed — old iOS jailbreak tweaks, dev tooling built to outlive the next
version bump.

#### Old iOS, kept alive

- **[revenant](https://github.com/kern0x1b/revenant)** — iOS 26 frameworks running on iOS 6.1.3: toolchain, emulator, recompiler and frameworks.
- **[classicgram](https://github.com/kern0x1b/classicgram)** — Telegram client for 32-bit armv7 iPhones and iPads on iOS 6, wearing the 2013 interface.
- **[kindle-sync-fix](https://github.com/kern0x1b/kindle-sync-fix)** — MobileSubstrate tweak fixing the Kindle Whispersync 417 error on jailbroken iOS 6.
- **[cydia](https://github.com/kern0x1b/cydia)** — the Cydia source that ships the iOS 6 tweaks above (SoundCloud API fix, Kindle sync fix).

#### JetBrains & editor tooling

- **[penstock-release](https://github.com/kern0x1b/penstock-release)** — BPMN 2.0 editor for Camunda 7 and 8 in JetBrains IDEs ([site](https://kern0x1b.github.io/penstock-release/); CLI via [homebrew-penstock](https://github.com/kern0x1b/homebrew-penstock)).
- **[cef-openapi-generator](https://github.com/kern0x1b/cef-openapi-generator)** — OpenAPI code generator for Chromium Embedded Framework with JetBrains Platform integration. 99%+ instruction coverage, real integration tests, not a demo.
- **[openapi-postmessage-generator](https://github.com/kern0x1b/openapi-postmessage-generator)** — generates the typed postMessage contract of an OpenAPI document: messages, envelopes, host handlers, a client and host-to-client events.
- **[vscode-intellij-code-formatter](https://github.com/kern0x1b/vscode-intellij-code-formatter)** — runs IntelliJ IDEA's actual formatting engine headlessly. No reimplementation, no drift from the real thing.
- **[vscode-intellij-theme](https://github.com/kern0x1b/vscode-intellij-theme)** — IntelliJ IDEA Islands colors, ported to VS Code.

#### Paseo plugins & agent tooling

- **[paseo-fleet](https://github.com/kern0x1b/paseo-fleet)** — model-agnostic multi-agent fleet skills (Coordinator, Worker, Reviewer) and event protocol for Paseo.
- **[paseo-gitlab](https://github.com/kern0x1b/paseo-gitlab)** — a mini GitLab inside Paseo: issues, merge requests, review, pipelines, with the token in the OS keychain.
- **[paseo-slack](https://github.com/kern0x1b/paseo-slack)** — Slack CLI, real-time event router and MCP server for AI agent fleets.
- **[paseo-usage-sidebar](https://github.com/kern0x1b/paseo-usage-sidebar)** — provider plan usage as a sidebar surface (fork).

No stats widget, no streak graph — the commits speak for themselves.
